# 수학 콘텐츠 생성 가이드

## 과목 특성
수학은 추상적 개념을 다루므로 **시각화**와 **단계별 접근**이 핵심입니다.

## 학년별 주제 예시

### 초등 저학년 (1-3학년)
- 덧셈, 뺄셈 기초
- 구구단
- 도형 인식
- 시계 읽기
- 분수 개념 (피자, 케이크로 시각화)

### 초등 고학년 (4-6학년)
- 분수 연산
- 소수
- 도형의 넓이, 둘레
- 비율과 비례
- 평균

### 중등 (1-3학년)
- 정수와 유리수
- 일차방정식
- 함수 그래프
- 도형의 성질
- 확률과 통계

### 고등 (1-3학년)
- 이차함수
- 지수와 로그
- 삼각함수
- 수열
- 미분과 적분 기초

## 시각화 전략

### 숫자 표현
- 블록/타일로 수량 시각화
- 수직선 활용
- 분수 파이 차트

### 도형
- 격자 기반 도형 그리기
- 드래그로 도형 변형
- 넓이 계산 시뮬레이션

### 함수/그래프
- 인터랙티브 좌표평면
- 점 찍기로 그래프 이해
- 슬라이더로 계수 조절

## 게이미피케이션 아이디어

1. **수학 퍼즐**: 숫자 배치, 연산 퍼즐
2. **계산 레이스**: 시간 제한 내 문제 풀기
3. **도형 빌더**: 블록으로 도형 완성
4. **방정식 밸런스**: 저울로 등식 이해

## 피드백 방식

- 정답: "훌륭해요! 🎉", 별/코인 획득 애니메이션
- 오답: "다시 생각해볼까요?", 힌트 제공
- 풀이 과정 단계별 표시

## 주의사항

1. 수학 기호는 정확하게 표현 (×, ÷, ≤, ≥, π)
2. 분수는 위/아래 정렬 (CSS flex 활용)
3. 소수점 자릿수 일관성 유지
4. 큰 숫자는 천단위 구분 (1,000,000)
