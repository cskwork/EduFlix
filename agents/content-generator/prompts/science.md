# 과학 콘텐츠 생성 가이드

## 과목 특성
과학은 **관찰**과 **실험**을 통한 발견이 핵심입니다.
가상 실험과 시뮬레이션으로 과학적 원리를 체험하게 합니다.

## 학년별 주제 예시

### 초등 저학년 (1-3학년)
- 동물과 식물
- 계절 변화
- 물의 상태 변화
- 소리와 빛
- 자석

### 초등 고학년 (4-6학년)
- 태양계와 지구
- 생태계
- 전기 회로
- 렌즈와 거울
- 화산과 지진

### 중등 (1-3학년)
- 세포 구조
- 물질의 상태 변화
- 힘과 운동
- 화학 반응
- 에너지 전환

### 고등 (1-3학년)
- 세포 분열
- 원소 주기율표
- 뉴턴 역학
- 화학 평형
- 전자기 유도

## 시뮬레이션 유형

### 물리 시뮬레이션
- 중력, 마찰력 시뮬레이션
- 진자 운동
- 파동 시각화
- 회로 시뮬레이터

### 화학 시뮬레이션
- 분자 결합 시각화
- 화학 반응 시뮬레이터
- pH 측정
- 상태 변화 실험

### 생물 시뮬레이션
- 세포 내부 탐험
- 생태계 균형 게임
- 인체 기관 탐색
- 광합성 과정

### 지구과학 시뮬레이션
- 태양계 궤도
- 기상 현상
- 지층과 화석
- 지진파 전파

## 게이미피케이션 아이디어

1. **가상 실험실**: 재료 조합, 결과 관찰
2. **탐험 모드**: 클릭하여 정보 발견
3. **퀴즈 챌린지**: 실험 결과 예측
4. **생태계 관리**: 균형 유지 게임

## 시각적 표현

### 확대/축소
- 현미경 효과 (세포, 미생물)
- 망원경 효과 (우주)
- 클릭/터치로 줌 인/아웃

### 단면도
- 생물 기관 단면
- 지층 단면
- 기계 내부 구조

### 애니메이션
- 물질 상태 변화
- 화학 반응 과정
- 생물 성장 타임랩스
