# EduFlix 프로젝트 소개

## 개요

EduFlix는 **Netflix 스타일의 인터랙티브 교육 콘텐츠 플랫폼**입니다. 초등~고등학생 대상으로 수학, 과학, 영어 과목의 교육 콘텐츠를 제공합니다.

## 핵심 특징

### 1. Netflix 스타일 UI
- 다크 테마 기반 모던 인터페이스
- 카테고리별 가로 스크롤 콘텐츠 행
- 반응형 디자인 (모바일/태블릿/데스크톱)

### 2. 인터랙티브 교육 콘텐츠
각 콘텐츠는 **7-Scene 구조**로 구성된 스토리텔링 학습:

```
Hook → Anchor → Story → Core → Visualize → Quiz → Wrap
(흥미) (연결)   (배경)  (핵심)  (시각화)   (확인) (정리)
```

### 3. AI 콘텐츠 자동 생성
- Claude AI가 학생의 관심사에 맞춘 맞춤형 콘텐츠 생성
- Gemini AI가 시각 자료 생성
- 비개발자도 콘텐츠 생성 가능

### 4. 샌드박스 실행 환경
- 각 콘텐츠는 독립된 HTML/CSS/JS로 구성
- iframe 샌드박스에서 안전하게 실행
- Three.js 기반 3D 콘텐츠 지원

## 사용 대상

### 학생
- 재미있게 수학/과학 개념 학습
- 시각적 상호작용으로 직관적 이해
- 자기 주도 학습 가능

### 교사
- 수업 보조 자료로 활용
- AI로 맞춤형 콘텐츠 생성
- 학생 참여도 향상

### 콘텐츠 제작자
- 코딩 없이 교육 콘텐츠 제작
- AI 지원 콘텐츠 생성
- 템플릿 기반 빠른 제작

---

## 기술적 장점

### 개발자 관점
- **Vue 3 + TypeScript**: 타입 안정성과 현대적 프레임워크
- **Bun**: 빠른 개발 서버와 패키지 관리
- **Vite**: 즉각적인 HMR과 빠른 빌드
- **Pinia**: 예측 가능한 상태 관리

### 콘텐츠 관점
- **독립형 콘텐츠**: 각 콘텐츠는 외부 의존성 없이 실행
- **반응형**: 모든 디바이스에서 최적화된 경험
- **확장성**: 새 콘텐츠 추가가 간단

## 프로젝트 구조 요약

```
EduFlix/
├── src/                # Vue 앱 소스
├── server/             # Bun API 서버
├── public/contents/    # 교육 콘텐츠 (HTML/CSS/JS)
├── agents/             # AI 콘텐츠 생성 에이전트
└── docs/               # 문서
```
