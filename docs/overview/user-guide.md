## 콘텐츠 탐색

### 카테고리
콘텐츠는 과목별로 그룹화되어 있습니다:
- **수학**: 기하, 대수, 확률 등
- **과학**: 생물, 화학, 물리 등
- **영어**: (현재 아카이브)

### 콘텐츠 카드
각 카드에는 다음 정보가 표시됩니다:
- **썸네일**: 콘텐츠 미리보기
- **제목**: 학습 주제
- **배지**: 학년/유형

### 콘텐츠 정렬
- **인기순**: 가장 많이 클릭된 콘텐츠 우선
- **최신순**: 최근 추가된 콘텐츠 가산점
- 자주 사용하는 콘텐츠가 왼쪽에 표시됩니다

## 콘텐츠 학습

### 콘텐츠 시작
1. 원하는 콘텐츠 카드 클릭
2. 전체 화면 뷰어에서 콘텐츠 로드
3. "시작하기" 버튼 클릭

### 학습 흐름

```
[Hook]      → 흥미로운 질문으로 시작
     ↓
[Story]     → 상황과 캐릭터 소개
     ↓
[Core]      → 직접 조작하며 개념 탐구
     ↓
[Quiz]      → 이해도 확인 문제
     ↓
[Wrap]      → 학습 내용 정리
```

### 상호작용
- **슬라이더**: 값을 조절하며 변화 관찰
- **버튼**: 다음 단계로 진행
- **드래그**: 요소 이동 (일부 콘텐츠)
- **클릭**: 선택 및 확인

## AI 콘텐츠 생성 (CreatorView)

> 참고: AI 기능은 API 서버가 실행 중일 때만 사용 가능합니다.

### 생성 단계

1. **관심사 입력**
   - 학생의 관심사를 최대 10개 입력
   - 예: "축구", "요리", "게임"

2. **과목 선택**
   - 수학 또는 영어 선택
   - (과학은 준비 중)

3. **학년 선택**
   - 초등 1~6학년
   - 중등 1~3학년
   - 고등 1~3학년

4. **생성 대기**
   - AI가 맞춤형 콘텐츠 생성
   - 진행률 표시

5. **완료**
   - 생성된 콘텐츠 바로 실행
   - 홈 화면에 자동 추가

## 모바일 사용

### 터치 제스처
- **탭**: 버튼 클릭, 선택
- **스와이프**: 콘텐츠 행 스크롤
- **핀치**: 확대/축소 (일부 콘텐츠)

### 모바일 최적화
- 44px 이상 터치 타겟
- 세로 모드 최적화 레이아웃
- 모바일 전용 네비게이션

### 주의사항
- 일부 3D 콘텐츠는 데스크톱에서 더 잘 작동
- 복잡한 상호작용은 터치보다 마우스 권장

## 문제 해결

### 콘텐츠가 로드되지 않음
1. 페이지 새로고침 (F5)
2. 브라우저 캐시 삭제
3. 다른 브라우저 시도

### 화면이 검게 표시됨
- 태블릿/데스크톱 전환 시 발생 가능
- 페이지 새로고침으로 해결

### AI 생성이 작동하지 않음
- Vercel 배포판은 정적 모드 (AI 비활성화)
- API 서버가 실행 중인지 확인
- `/api/health`의 `llm.keyConfigured`와 `ZAI_API_KEY` 설정 확인

### 인기 콘텐츠가 표시되지 않음
- 백엔드 서버가 필요 (SQLite DB)
- 개발: `bun run dev:all` 실행
- 프로덕션: Cloudflare Tunnel 사용

## 자주 묻는 질문

### Q: 콘텐츠를 저장할 수 있나요?
A: 현재 북마크 기능은 없지만, 브라우저 북마크로 URL 저장 가능합니다.

### Q: 오프라인에서 사용 가능한가요?
A: 현재 오프라인 모드는 지원하지 않습니다. PWA 지원 예정입니다.

### Q: 새 콘텐츠는 언제 추가되나요?
A: AI 생성 기능을 통해 직접 맞춤형 콘텐츠를 생성할 수 있습니다.

### Q: 학습 기록이 저장되나요?
A: 클릭 기록은 저장되어 인기순 정렬에 반영됩니다. 상세 학습 기록은 개발 예정입니다.
