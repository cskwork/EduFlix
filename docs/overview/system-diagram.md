## 데이터 흐름

### 1. 콘텐츠 로딩 흐름

```
사용자 → HomeView → ContentCard 클릭
                          │
                          ▼
               ContentView (뷰어)
                          │
                          ▼
          iframe 로드 (public/contents/...)
                          │
                          ▼
              EduFlixEngine 초기화
                          │
                          ▼
              Scene 전환 (hook → wrap)
```

### 2. AI 콘텐츠 생성 흐름

```
사용자 → CreatorView → 관심사/과목/학년 입력
                                │
                                ▼
                   POST /api/generate (작업 생성)
                                │
                                ▼
                         art-assets 서버
                                │
                     ┌──────────┴──────────┐
                     ▼                     ▼
               Claude API           콘텐츠 리뷰/개선
               (콘텐츠 생성)               │
                     │                     │
                     └──────────┬──────────┘
                                ▼
                     파일 시스템에 저장
                                │
                                ▼
                     index.json 카탈로그 업데이트
                                │
                                ▼
                     사용자에게 완료 알림
```

### 3. 클릭 추적 흐름

```
사용자 → 콘텐츠 카드 클릭
              │
     ┌────────┴────────┐
     ▼                 ▼
localStorage      API 서버
(클라이언트)      (서버 모드)
     │                 │
     ▼                 ▼
클릭 통계 저장    SQLite DB 저장
     │                 │
     └────────┬────────┘
              ▼
     홈 화면 정렬에 반영
     (인기 콘텐츠 우선)
```

## 컴포넌트 구조

### 프론트엔드 컴포넌트

```
src/
├── views/
│   ├── HomeView.vue        # 메인 홈 화면
│   ├── ContentView.vue     # 콘텐츠 뷰어 (iframe)
│   ├── CreatorView.vue     # AI 생성 마법사
│   └── NotFoundView.vue    # 404 페이지
│
├── components/
│   ├── common/
│   │   ├── AppHeader.vue   # 상단 헤더
│   │   └── ModeToggle.vue  # 정적/동적 모드 토글
│   │
│   ├── home/
│   │   ├── ContentCard.vue # 콘텐츠 카드
│   │   └── ContentRow.vue  # 가로 스크롤 행
│   │
│   ├── viewer/
│   │   └── ContentViewer.vue # iframe 래퍼
│   │
│   └── creator/
│       ├── CreatorWizard.vue # 생성 마법사
│       ├── InterestInput.vue # 관심사 입력
│       └── SubjectSelect.vue # 과목 선택
│
└── stores/
    ├── content.ts          # 콘텐츠 상태 관리
    └── generation.ts       # 생성 상태 관리
```

### 백엔드 라우트

```
server/
├── index.ts               # 서버 진입점
├── routes/
│   ├── content.ts         # /api/content - CRUD
│   ├── generate.ts        # /api/generate - AI 생성
│   └── recommendations.ts # /api/recommendations - 추천
│
└── services/
    ├── art-assets.ts      # art-assets 연동
    ├── content-sync.ts    # 콘텐츠 동기화
    └── health.ts          # 헬스 체크
```

## 기술 스택 상세

| 레이어 | 기술 | 역할 |
|--------|------|------|
| UI 프레임워크 | Vue 3 | 반응형 UI 컴포넌트 |
| 타입 시스템 | TypeScript | 타입 안정성 |
| 상태 관리 | Pinia | 전역 상태 관리 |
| 번들러 | Vite | 빠른 개발/빌드 |
| 런타임 | Bun | 서버 + 패키지 관리 |
| AI | Claude + Gemini | 콘텐츠 생성 |
| 3D | Three.js | 3D 콘텐츠 렌더링 |
| DB | SQLite | 추천/클릭 데이터 |
