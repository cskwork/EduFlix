# 수업 작업실

`/studio`에서 초·중·고 수업 자료를 직접 구성합니다. LLM 제공자 설정 없이도 편집, 저장, 학생 미리보기와 파일 배포를 사용할 수 있습니다.

## 수업 만들기

1. 시작 자료를 복사하거나 새 수업을 엽니다. 시작 자료의 학년은 활용 제안입니다.
2. 학년, 과목, 시간, 학습 목표, 선수 지식과 교사 진행 안내를 입력합니다.
3. 개념 설명, 탐구 활동, 확인 문항, 성찰·적용 블록을 추가하고 순서를 바꿉니다.
4. 확인 문항은 보기 2~6개, 정답 하나와 해설을 입력합니다. 학생의 채점은 교사가 편집한 정답을 사용합니다.
5. 학생 화면을 확인한 뒤 저장합니다. 미완성 수업도 미리 볼 수 있지만 필수 내용이 없는 수업은 저장하거나 내보낼 수 없습니다.

수업은 현재 브라우저의 IndexedDB에 저장됩니다. 계정이나 기기 간 동기화를 제공하지 않습니다. 저장 공간이 삭제되면 자료가 사라지므로 파일을 백업하세요. 저장하지 않은 변경이 있을 때 다른 수업을 열거나 화면을 떠나면 확인합니다.

## 배포와 다시 편집하기

- JSON은 수업 원본 데이터입니다. 다른 브라우저에서 가져와 수정할 수 있습니다.
- HTML은 외부 라이브러리와 네트워크 없이 열 수 있는 학생용 수업 파일입니다. EduFlix가 내보낸 HTML에는 편집 데이터도 포함되어 다시 가져올 수 있습니다.
- 파일 가져오기는 기존 수업을 덮어쓰지 않고 새 사본을 만듭니다. 일반 웹페이지나 임의 HTML은 수업 파일로 가져올 수 없습니다.
- 학생의 답과 활동 메모는 해당 화면에만 남으며 서버로 전송하거나 저장하지 않습니다. 수집이 필요하면 별도의 제출 방법을 안내하세요.
- 홈에서 저장한 수업을 열 수 있습니다. 해당 수업의 편집 버튼은 정답과 해설을 함께 관리하는 수업 작업실로 연결됩니다.

수업 전에 목표와 활동의 관계, 정답·해설, 사실·출처, 학생의 읽기 수준을 확인하세요. 시작 자료는 참고 자료를 바탕으로 작성한 원본 활동이며 공식 교육과정 인증이나 교사 심사 완료를 의미하지 않습니다.

## AI로 편집 가능한 초안 만들기

수업 계획에 제목과 학습 목표를 입력한 뒤 `AI로 수업 초안 만들기`를 누르세요. 학습 블록이 비어 있거나 미완성이어도 요청할 수 있습니다. AI는 수업 데이터만 작성하고, 앱의 기존 학생 화면이 보기·정답·해설을 표시하고 채점합니다.

이미 작성한 블록이 있으면 교체 전에 확인합니다. 생성 또는 검토에 실패하면 현재 수업을 유지합니다. 생성 중 사람이 수업을 수정한 경우에도 자동으로 덮어쓰지 않습니다. 성공한 초안은 아직 저장되지 않은 상태이며 교사가 수정하고 저장해야 합니다.

초안 작성과 교육 검토는 총 285초를 공유하고, 문제가 있으면 한 번 재생성합니다. 자동 검토는 오류를 줄이는 보조 단계이며 사실 정확성이나 학년 적합성을 보증하지 않습니다. 내용을 읽고 정답을 직접 확인하세요.

로컬과 서버리스 배포 모두 기존 `/api/generate`를 사용합니다. 이 기능에는 Z.ai 제공자와 `ZAI_API_KEY`가 필요합니다. Codex 팩토리 설정에서는 명확한 오류를 반환하며 다른 제공자로 몰래 전환하지 않습니다. 기존 관리자 인증 설정을 그대로 적용합니다.

## 자유로운 AI 콘텐츠로 확장하기

생성 기능을 사용할 수 있는 배포에서는 `이 수업으로 AI 콘텐츠 만들기`를 누르면 기존 제작기로 이동합니다. 학년, 난이도, 목표, 시간, 본문과 정답·해설, 출처를 전달하며 교사가 제작 방식을 선택한 뒤 생성을 시작합니다. 전달 내용이 허용 길이를 넘으면 잘라서 보내지 않고 길이를 줄이도록 안내합니다.

실제 LLM 요청은 기존 제공자와 인증 설정을 사용합니다. 입력 형식 검사와 수업 원본 편집은 생성 결과의 사실 정확성을 보증하지 않습니다. 생성이 실패하면 제작기의 입력을 유지한 채 수정하거나 재시도할 수 있습니다.

## 구현과 호환성

수업 원본 계약은 `src/types/lesson.ts`, 검증·저장·독립 HTML 렌더링은 `src/services/studio/lesson.ts`에 있습니다. 기존 로컬 콘텐츠 저장소를 사용하며 추가 데이터베이스 마이그레이션이 없습니다. 신규 학생 미리보기는 same-origin 권한이 없는 iframe에서 실행됩니다. 일반 생성 콘텐츠의 기존 iframe과 임의 스크립트 채점 방식은 변경하지 않았습니다.

학교 계정, 중앙 저장, 제출·채점 수집, 실시간 공동 편집은 현재 범위에 포함하지 않습니다.

## 기존 콘텐츠 회귀 검사

`npm run test:content-quality`는 기존 콘텐츠에서 수정한 계산·채점·문항 진행 동작을 세 그룹으로 순서대로 검사합니다. 실제 수업 소스를 happy-dom과 VM에서 실행하며, 잘못된 답과 반복 제출 등 회귀 사례를 포함합니다. 검사가 실패하면 명령도 실패하며 결과는 표준 출력에만 표시합니다. 이 검사는 브라우저의 화면 배치나 WebGL 렌더링 검증을 대신하지 않습니다.
