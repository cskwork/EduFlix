# 2026-01-23 변경 사항

## UI/UX 개선 (Netflix 스타일 디자인 적용)

### 메인 페이지 (HomeView)
- **히어로 섹션 개선**: 
  - 전체 화면(85vh) 높이의 몰입형 비주얼 적용
  - 배경 그라디언트 및 비네트 효과 추가로 시각적 깊이감 향상
  - '재생' 및 '상세 정보' 버튼 스타일 적용
  - 헤더 영역까지 배경이 확장되도록 레이아웃 조정

### 콘텐츠 카드 (ContentCard)
- **비율 변경**: 기존 1:1 비율에서 16:9 시네마틱 비율로 변경
- **스타일 개선**:
  - 카드 너비 확대 (200px -> 280px)
  - 불필요한 테두리 및 장식요소 제거로 깔끔한 디자인 구현
  - 호버 시 확대(Scale) 효과 강화
  - 썸네일 아이콘 인터랙션 추가

### 콘텐츠 목록 (ContentRow)
- **스크롤 컨트롤 개선**:
  - 기존 상단 배치 버튼을 콘텐츠 영역 오버레이(Overlay) 방식으로 변경
  - 호버 시에만 버튼이 표시되도록 하여 시각적 방해 최소화
  - 전체적인 디자인 일관성 확보

### 헤더 (AppHeader)
- **스크롤 인터랙션**:
  - 최상단에서는 투명한 배경 적용
  - 스크롤 시 솔리드(Solid) 배경으로 전환되는 기능 추가

## 버그 수정
- 개발 환경에서 iframe sandbox에 allow-same-origin을 조건부 허용하여 콘텐츠 미리보기 CORS 오류를 완화
- 공통 콘텐츠 스타일에 html/body 높이 및 배경 설정을 추가해 콘텐츠 흰 화면 문제를 완화
- 스토리 캐릭터 이미지가 경로 문자열로 표시되던 문제를 수정하여 이미지가 정상 렌더링되도록 개선
