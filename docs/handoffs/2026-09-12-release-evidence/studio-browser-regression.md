# 작업실 정답 삭제 회귀

2026-09-12, 실제 Chrome UI, `http://127.0.0.1:5173/studio`.

1. 분수 시작 자료를 복사하고 네 번째 블록의 정답 보기를 삭제했습니다. 처음에는 삭제 후 다른 보기가 선택되어 저장됐습니다.
2. 원본 파일과 Vite의 `/src/views/StudioView.vue` 응답을 비교했습니다. 서버는 변경 전 `quiz.answer = 0` 코드를 제공하고 있었습니다. 새 코드 결함과 오래된 개발 서버 응답을 구분했습니다.
3. Vite를 재시작해 7.3.6 실행과 `removeQuizChoice`가 포함된 최신 응답을 확인하고 Chrome을 새로고침했습니다.
4. 직접 만든 검증용 사본에서 보기 세 개를 구성한 후 정답 보기를 삭제하고 저장을 눌렀습니다. 두 라디오가 모두 선택되지 않은 상태로 남았고 `문항 4의 보기·정답·해설을 확인하세요. / Complete choices, answer and explanation.` 오류가 표시됐습니다.
5. 수학적으로 올바른 `2/6` 보기를 정답으로 선택한 뒤 저장했습니다. `Saved in this browser. Export JSON to keep a backup.` 및 선택된 정답 라디오를 확인했습니다.

검증 사본은 `검증용 분수 수업 · 정답 재선택 확인`이라는 제목으로 저장했고, 정답과 해설을 올바르게 복원했습니다. 기존 사용자 자료를 삭제하거나 저장소를 초기화하지 않았습니다. 큰 한글 JSON/HTML 파일 회귀는 제품 단위 테스트로 확인됐으며 이 기록은 해당 파일의 실제 브라우저 가져오기를 주장하지 않습니다.
